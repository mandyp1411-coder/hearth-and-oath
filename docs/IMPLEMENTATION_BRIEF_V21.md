# Hearth & Oath — audit implementation brief

Improve the existing game using the two completed audits. Preserve the text life RPG, whole illustrated portraits, age and heritage rules, cultural names, player freedom, existing saves and hosting audience.

Ship a coherent, tested release with these priorities:

1. Correct inconsistent roleplay: age-appropriate NPC dialogue, personality effects on committed replies, oath consequences for coercion, and personally relevant news.
2. Make combat decisions reliable: preserve bloodless physiology, temper lifetime skill conversion, improve class scaling and companion growth, retain inspected knowledge, and provide controlled nonlethal attacks for capture.
3. Build exploration around saved knowledge and position: real six-neighbor hex movement, unknown/rumored/charted/visited distinctions, sourced lore leads, city interiors sharing existing services, and dungeon graphs that hide unvisited room names. Use the existing calendar and interruption rules.
4. Protect saves and improve navigation: review imports before replacement, retain a recoverable prior save, preserve spatial context and targeting focus, show consistent trait previews, and add readable display settings and journal search.
5. Connect lore and audio to lived places: date history against the world clock, distinguish current conditions from old accounts, fix context recreation, add place-specific music and phrase variation, and sound completed outcomes rather than attempted commands.

Acceptance: reject invalid commands without spending resources; cancel imports without changing saves; preserve identity and pending commitments through reload and succession; never reveal hidden locations, foes or rooms; keep ordinary travel accessible; test new behavior directly and run the full existing regression suite.

Freeze the candidate and simulate at least 100 additional distinct seeded lives through public game commands. Retain failures and distinguish driver defects from game defects. Record completion, reload integrity, portraits, combat, exploration, law, careers and heirs. Fix observed bugs and rerun affected checks. Publish only the final tested candidate. Report what changed, evidence, remaining gaps, and the absence of browser/device listening verification when unavailable. Do not describe automated lives as human reviews.

The world UI lists sourced places only. The existing public road command can request directions to a named destination from local carriers; successful departures add that attributed rumor and still spend every normal road day. City interiors use public room graphs and free walking. Authored dungeon doors retain their existing one-day expedition cost. These are explicit boundaries of this release.
