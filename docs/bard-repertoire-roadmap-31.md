# Original repertoire and three-inn circuit

This bounded candidate starts at public v0.49.0 `4e91d5d`. It adds optional adult civilian art, not another professional work route. The existing Bard profession, wages, practice, commissions, skills and authored `pastime_performance` remain unchanged.

The player can keep up to three original four-line fictional pieces with an actual composition place/day, their own composer credit, two authored endings and explicit manuscript-copy permission. A changed ending is a new private revision. One attended rehearsal day prepares a chosen revision/arrangement; each circuit recital takes two actual attended days. No Gold, career days, commissions or skill is awarded. Reception gives bounded Joy only once.

The optional finite circuit names the actual Tavern rooms at `home`, `brook` and `city`, using this world's existing place names. Acceptance verifies all three operating inn services and open-road graph connectivity. Targets stay fixed afterward. Closures and unavailable named hosts allow withdrawal, not an invented venue or an automatic successor. Travel remains the existing real road system.

A quiet solo and a shared refrain suit different local audiences. Piece relevance, rehearsal of this exact version and actual previous performance affect reception. Previous performance gives the performer's confidence; it does not give a new audience knowledge of another inn. Public rendition once and permission for a manuscript copy are separate. A private draft is never made globally public just because one version was heard.

Bookings and heard receipts freeze the full revision, original words, source, credits, arrangement, public permission, venue, named listener and actual previous-performance reference. Later revision/deletion cannot rewrite them. Only the first actual host has one optional explicit “Talk about [piece]” scene, on a later day while actually present, available and unblocked. Ordinary Talk, family, Gateyard, work and generic follow-ups are not replaced. The captured scene has no extra time, relationship or resource reward.

Data is optional and created only by explicit manuscript/circuit choices. Migration does not invent old manuscripts, audiences or memories. A successor gets no private repertoire, rehearsal readiness or personal recognition. Heard identities remain historical references in NPC16; an ignored circuit does not freeze tenure. Only an actual pending recalled-performance scene can pin its current participant, like other pending named scenes.

The player's book is available as a disclosure in Home and Social & Fun, with a separate inn inquiry. It labels private reading explicitly, escapes text, displays original sources/credits, previews reception and costs, and exposes saved continuation/withdrawal. Completed public renditions appear in Journal Notes. New notes use literal edition-30 records; only the exact new recalled-performance scene bypasses generic prose rewriting.
