classic script. The shared adapter now executes the exact unchanged module
with its real asynchronous startup. Ten checkers use full module scope and
native per-realm media parsing. Twenty older probes retain their existing
classic-prefix lexical observations and execute the exact async tail as a
module; seventeen of those share only the verified immutable inert media
table between sessions. Native `JSON.parse` is restored before app startup.
These scoped probes do not replace full-module or browser evidence.

The original 15-second startup deadline is retained. Earlier-save comparisons
include actual edition metadata, and rule-aware export filenames are checked.
The final native fixture returns from a reopened Book through the ordinary
Day control before attempting field work; that navigation must leave the
whole save unchanged. It passed in 17.381 seconds with fee/keep parity,
module privacy, exact export, three saves and backups, and zero network
attempts. Its original navigation failure remains in the archived B report.
No original failure is relabelled as a pass.

## Browser observations

content and 165.78125px down the phone content, within the Bible's 200px
